# DubViet SaaS - Bản quyền của Trieuanhthu-ai

Web dịch video AI đa ngôn ngữ, bạn quản lý khách hàng và cấp quyền thủ công.

## Cài đặt nhanh (5 phút)
1. Upload toàn bộ thư mục này lên GitHub repo `dubviet-saas`
2. Vào vercel.com → New Project → chọn repo → Deploy
3. Vào supabase.com tạo project miễn phí → copy URL và KEY
4. Vào Vercel → Settings → Environment Variables:
   - NEXT_PUBLIC_SUPABASE_URL=...
   - NEXT_PUBLIC_SUPABASE_ANON_KEY=...
   - ADMIN_EMAIL=email của bạn
5. Redeploy

## Quản lý giá
Vào /admin → Gói cước → sửa giá 99k, 210k, 499k trực tiếp. Không cần code.

## Cấp quyền cho khách
Khách chuyển khoản → bạn vào /admin → bấm "Kích hoạt Pro"
